# Repository Guidance

Read [CONTEXT_MAP.md](CONTEXT_MAP.md) before modifying this project. It is the shared architecture, workflow, keybinding, and validation map for coding agents and human contributors.

Keep the map current when a change moves an architectural entry point, changes an interaction contract, or adds a major subsystem. Preserve unrelated working-tree changes and treat `Assets/Scenes/Main.unity` as the active production scene unless the task explicitly says otherwise.
