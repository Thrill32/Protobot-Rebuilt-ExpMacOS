# Connected-mode mutation coverage

The development switch is required. Only the rows marked supported may mutate a connected document. The offline editor retains its existing paths. This audit is a release gate, not a claim of complete collaboration coverage.

| Mutation / action | Connected alpha | Real entry point / guard |
| --- | --- | --- |
| Host current committed catalog build | Supported, including valid chains; no custom models | `CollaborationSession.HostAsync`, `CollaborationScene.CaptureDocument` validate/normalize part and chain identities before publishing |
| Join / reconnect / remote apply | Supported | shared client snapshot/cursor + `CollaborationSession` main-thread queue; `CollaborationScene` applies stable IDs, poses, materials, chains and detector refresh |
| Owned helper restart / reopen recovered room | Supported with matching catalog/version | `CollaborationHost.RestartAsync`, `CollaborationRecovery`, scoped client cache and `RoomStore`; explicit Resume uses Save As and never auto-opens a listener |
| Catalog placement / hole, hardware and gear snapping | Supported, one accepted create per stamp | `Placement.Place` → `PlaceCatalog`; geometry queries collect versioned read dependencies through `CollaborationScene.BeginReads/Read/EndReads`; stale targets reject atomically |
| G / R on a placed selection/assembly | Supported | `KeyboardTransformTool.BeginSelection` acquires full-set lease; `CompleteConfirmation` submits exact resolved poses; cancellation restores baseline/releases lease |
| Delete selected parts / assembly | Supported | `ObjectDeletor` → full-set reservation + atomic `DeleteParts`; incident chains and all of their endpoints join the reservation, and affected chain records are removed in the same transaction |
| Save / Save As | Supported independently | `BuildsManager` waits pending barrier, captures accepted snapshot/hash and keeps each participant's path/marker |
| Open / New / leave / continue offline | Supported | normal unsaved handling, detach, accepted baseline preservation; stale async results cannot act on a new session |
| Selection / camera / grid / hole visibility | Local only | ordinary inputs remain available; selection history recording is suppressed in connected mode |
| Transform handles / exact axis input | Supported | `ClickDragTool` waits for a full-set reservation; `MovementManager` submits resolved poses; Escape/pointer release cancels waiting grants |
| Move / G → H / Connect | Supported | `MoveToolManager` reserves saved bodies only, excluding selection pivots/hole markers; `Placement` submits poses once with target versions; `ConnectTool` submits a reserved translation with source/target preconditions |
| Paint / Default reset | Supported | `ColorSelectionResponse` → reserved `SetParts`; remote apply paints body slots and restores generated defaults |
| Existing-part parameter replacement | Supported | `AddPropertiesUI` → reserved `SetParts`; regeneration preserves identity, paint, state and valid selection, with collider/detector refresh |
| Alt copies / P stamping | Supported for catalog parts, including contained chains | G/R and handles latch Duplicate before waiting; `TransformAndCopy` commits movement, new IDs and chains whose complete endpoint set was copied atomically; `SelectionPlacementData` stamps frozen copies and remapped chain topology through one `AddParts` transaction |
| Paste / build import | Supported for catalog-only builds, including contained chains | `BuildTransferTool` rejects custom geometry, malformed/nonphysical chain payloads and sets beyond the 256-mutation bound before placement; new part/chain identities commit atomically and selection follows accepted materialization |
| Selection export / clipboard copy | Existing local read-only paths | ordinary modal guards apply; no shared mutation |
| Portable room export for CLI | Supported, catalog-only accepted snapshot including chains | `CollaborationSessionExport.ExportRoomAsync` waits pending outcomes, captures before the native dialog and preserves local save state; `RoomExport.CreateRoom` seeds a fresh generation/history |
| Server connection test / CLI doctor | Read-only room probes | `ConnectionDoctor` joins viewer identities, checks the chosen event transport and leaves; diagnostic reports exclude credentials |
| Custom model import / mounts / depth / grid edits | Disabled; custom documents cannot host | `CustomModelTool` guard and host preflight |
| Simulation scrub / numeric entry / timeline playback | Private, including for viewers | `SimulationTool` owns temporary transforms; no room lease or preview frames; Save uses accepted poses; a shared edit resets the local preview before remote apply |
| Simulation mouse confirm / timeline Set pose | Supported for catalog mechanisms | `SimulationTool.Commit` → `CommitResolvedPosesAsync`; frozen live world poses, scoped full write-set lease and exact mechanism revision precondition; one personal undo step |
| Chains | Supported for existing catalog builds and C-key add/remove | `SimulationTool.ChainSelected` → endpoint reservation + atomic `SetChains`; stable chain IDs/versions/tombstones participate in hashing, persistence and personal history; duplicate topology and missing endpoints reject |
| Personal Undo / Redo | Supported for this room membership; persisted in durable rooms | `StateSystem` → `Undo`/`Redo`; authority-owned before/after history, monotonic resurrection, lease conflict checks and invalidation after another participant touches an affected entity |
| Legacy shaft-position buttons | Supported | `NewMoveShaftTool.SetSharedShaftPosition` resolves the existing pose math and submits a reserved immutable result; bracket/pivot selection stays local |
| Owner document replacement / room admin / revocation | Unavailable | no public endpoint is exposed for these mutations |

Client mutations are `AddParts`, `SetPoses`, `SetParts`, `TransformAndCopy`, `DeleteParts`, `SetChains`, `Undo` and `Redo`. Only the authority can create `RestoreParts` inverse events; clients cannot supply inverse content. Unknown mutations fail. The authority does not accept a client author ID, run Unity physics or infer snapping. Creates require fresh stable IDs; a chain carried by `AddParts` or `TransformAndCopy` may reference only endpoints created in that same transaction, so fresh endpoints need no pre-existing lease. Pose writes preserve identity/catalog/paint/state; every ordinary existing write needs the owning live lease and expected entity version. Other chain edits additionally require expected versions and leases for every existing endpoint. Private mechanism results require the exact document revision used to evaluate them. Helper/client version 0.4.1-alpha is checked at startup and join. History checks part/chain reservations atomically and refuses to overwrite another participant’s edits. Durable rooms persist receipts, identities and personal history across restart; ephemeral rooms retain them only in memory. Explicit Leave revokes that membership. Restart clears leases/access sessions/ghosts. Participant pending IDs are saved before submission and resolved without automatic replay. Preview geometry has no SavedObject, collider, detector or save ownership. Main scene wiring is installed at runtime rather than serialized into the production scene.
